Digimon Color 传输工具

把原机 ROM 写进 AI Passport，或者导出/导入宠物存档。固件本身不含 ROM，ROM 需自备。

需要电脑上的 Chrome / Edge（Web Serial），并且本页必须从 https 或 localhost 打开。用 USB-C 线连上设备，先点“连接设备”。

导出的是整个 save 分区原样镜像；导入后设备需要重启才会读到新存档。

步骤

  1. 用 USB-C 连接设备，点“连接设备”，在弹窗里选该设备对应的串口。
  2. 选 ROM 文件（8 MiB 的 .bin），点“上传 ROM”。只传输有数据的页，约 2.5 MiB。
  3. 传完设备自动重启并进入游戏；重新“连接设备”后可以导出存档。
