## 1. 这是什么

在 **FoloToy AI Passport**（ESP32-C3，8 MB flash，无 PSRAM，320×240 ST7789P3，A/B/C 三键）上，
用真模拟的方式跑 Bandai **Digital Monster Color**（彩屏元祖，MAME 机种名 `digicolr`）的原机 ROM。
CPU / 定时器 / 中断 / SPI flash / LCD 控制器 / 按键全部按原机行为实现，不重画素材、不重写玩法。

## 3. 五条已经实测、不要重测的硬件事实

1. **guest 可见区是 96×96，取 GRAM 的 (0,18) 起**。
   MAME：`m_screen->set_visarea(0, 95, 18, 113)`（`ref/generalplus_gpce4.cpp:397`）；
   抓帧也证实内容严格落在 x 0..95、y 18..113，矩形外全 0。
   **这就是"画面偏左"的真根因**——旧代码取 128 宽，右侧 32 列是空的，2× 之后右边多出 64 px 黑。
2. **面板只写不读**。ST7789 的 SPI 是单向的，`T` 抓的是 `fb[]` 不是面板。
   砖墙、电量数字、设置卡都直推面板，**抓帧看不到它们**，只能目视或看离线预览。
3. **ROM 不产生可用的音频**。`dac=0 pwm=0`（实测），MAME 标 `MACHINE_NO_SOUND`。
   设备现在所有的声音都是 `audio.c` 的方波合成器（按键 `audio_beep(1760,18)`）。
   → **主画面 A+C 的"静音"在本机永远没有反馈**，这不是 bug。
4. **三个键在一条电阻梯上**，物理上不可能同时按出 A+C / A+B。
   官方手册里这两条组合键是真的功能（时钟画面改时间 / 墓碑孵蛋），所以只能由模拟器代发。
5. **CW2017 电量计和 ES8311 codec 共用 I2C0**（SDA 10 / SCL 7）。
   总线由 `audio.c` 开，`battery.c` 必须复用它（`audio_i2c_bus()`），
   **不能另开第二个 master**，且 `battery_init()` 必须在 `audio_init()` 之后。

## 4. 会咬人的坑（都是这一轮踩过的）

| 坑 | 症状 | 正确做法 |
|---|---|---|
| **改完代码设备表情不变** | 编译过了，行为还是旧的 | `edit` 写入的 mtime 可能比编译产物旧，ninja 判定无需重编。**改完源码先 `(Get-Item x).LastWriteTime = Get-Date` 再 build**，或 `-Clean` |
| **共享缓冲区只按一个消费者定尺寸** | 长按弹卡就重启（`Load access fault`） | `s_strip` 同时给 blit（12,288 B）和菜单 band（15,360 B）。尺寸取两者最大 + `static_assert` 钉死 |
| **以为 blit 会顺手重画窗口外** | 关设置卡后上下留两条卡色 | blit 只管窗口（192×192）。窗口外必须有显式重画路径，现在是 `panel_draw_bezel()` |
| **长按手势污染游戏** | 长按 A 后游戏画面先变了 | A 按下时**扣住不投递**，松手才决定：短按补发脉冲，长按只开菜单。三处要一起堵（`s_hold_left` / `latched` / `mask` 表达式） |
| **串口一连上就复位** | 菜单"自己关了"、状态丢失 | USB-Serial-JTAG 对 DTR/RTS 敏感。一次测试的操作序列必须在**同一个串口会话内**完成 |
| **只看 SOC 判断电量** | 0% 分不清"没电"还是"没算完" | 同时看 `battery_mv()`：`0 mV` 才是没电池，`4 V + 0%` 是芯片还在算 |
| **`int(x)` 在 C 里非法** | `control reaches end of non-void function` | C 用 `(int)x`；`app_main.cpp` 是 C++ 才两种都行 |
| **`snprintf` 缓冲区按最大 int 算** | `-Werror=format-truncation` | 装一个 `%d` 加 `%` 至少要 13 字节，`char txt[16]` |
| **改错 version.txt** | `VER` 还是旧版本 | 真正的是 `firmware/digicore-c3/version.txt`，仓库根没有；改完还要碰 `main/CMakeLists.txt` 触发 reconfigure |
| **`unsigned(x)` 当强制转换** | `expected primary-expression before 'unsigned'` | `unsigned` 是类型关键字，写 `(unsigned)x` 或 `static_cast<unsigned>(x)` |

## 5. 现在能干什么（已验收）

- 开机 → 标题画面 → 短按 A 进 LOAD/RESET → C 到宠物主画面
- 长按 A 1.2 s → **设置卡**（9 行），第 0 行 `SEND A+C`、第 1 行 `SEND A+B`
- A 换行、B 改值/执行、C 退出；`SAVE OUT` / `SAVE IN` 对应快照存/取
- 两条 chord 都先 blank 700 ms 再按住 3.2 s（B 还按着直接跳过去会被 ROM 丢掉）
- 主画面是 RETAIL (style C) 壳：128×128 A8 砖墙平铺（从 digimon-passport 原样抄）+ 金属内框
  （204×204 r8，1 px 高光）+ well（198×198 r4）+ 面板自己的 30 px 圆角遮罩
- 右下角 `#EDEDE6` 电量百分比，-16/-4 边距，每 30 s 刷新，只在变化时重画
- **发布版不含 ROM**：网页（`tools/dmc_web.html`，Web Serial）上传 8 MiB 原机镜像 →
  浏览器稀疏化 → 611 页 / 2.5 MiB / 24 s；存档 128 KiB 导出导入往返一致
- **无 ROM 时不再死机**：屏幕 `NO ROM / OPEN WEB TOOL`，控制台继续响应等上传
- 长按 B 是纯游戏键（不再开菜单）

## 6. 待办（按性价比）

1. **A+B 的真实验收**：`port=ffe7` 只证明送到 PORTA。真验收点在**墓碑画面**（宠物死亡后孵新蛋），
   当前存档走不到。要验就复制一份 `save` 分区做实验，别碰现有存档。
2. **`SEND A+C` 在时钟画面复验**：手册说 A+C 只在时钟画面有可见效果（改时间），
   这条在 v1.2.2 上验过有效，v1.3.x 改了手势后应在时钟画面再确认一次。
3. **网页烧固件**：现在烧 app 仍要 esptool；网页里实现 esptool stub + flash 协议才能一键装。
4. **音频**：要做真音频，先在真机发声瞬间抓 `dac/pwm/spi` 计数，找出那条没建模的通路（当前全是 0）。
4. **guest 实时率 ~27%**：这是模拟器算力上限，不是渲染问题（`blit_pct` 只有 0–1%）。
   提速要动 AOT/解释器，别动显示路径。
5. **16 s 空闲 park 点**：ROM 写 `0x3036` 后 park 到 `0x200300`，若停在标题画面按键会失效。

金属内框已在 v1.5.0 做掉；**钥匙孔造型**没做，理由和位置参数见 `HANDOFF_UI_POSITION.md` §18.9。

## 8. 常用命令

```powershell
# 构建（不烧写）
cd firmware\digicore-c3
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1

# 只烧 app 分区（不动 bootloader / ROM / 存档）
$py="C:\Users\DuWeisi\.espressif\python_env\idf5.5_py3.11_env\Scripts\python.exe"
& $py -m esptool --chip esp32c3 -p COM4 -b 460800 write_flash --flash_mode dio `
     --flash_freq 80m --flash_size 8MB 0x10000 build\digicore-c3.bin

# 串口自检 / 诊断图 / 对齐靶
& $py tmp\s29\align.py V --noreset
& $py tmp\s29\align.py G 2 --noreset      # 面板四边白框
& $py tmp\s29\align.py G 3 --noreset      # 对齐靶（绿框 = 当前窗口落点）
& $py tmp\s29\align.py E 64 --noreset     # 把窗口左边放到面板 x=64

# 抓 guest 帧（96x96）与面板预览（砖墙 + 电量）
& $py tmp\dump_fb.py COM4 tmp\x.png "2" --noreset
& $py tmp\s31\bezel_preview.py tmp\x.png 92

# 手势回归（长按 A 开卡 / B 发 A+C / 长按 B 不弹菜单）
& $py tmp\s31\gesture.py
```

串口命令速查：`V` 几何 · `S` 统计+GEST · `T` 抓 fb · `K <mask> <frames>` 注入按键（1=A 2=B 4=C）·
`Z <addr>` 读内存/IO · `D`/`U` 快照 · `E` 窗口落点 · `G 0..3` 诊断。
